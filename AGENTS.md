# Правила работы

Прочитай SPEC.md перед изменениями. Это источник требований, разрешений, плана и прогресса. После каждой итерации актуализируй SPEC.md: изменения, проверки, оставшаяся работа и следующий шаг. Объясняй код и решения на русском. Не переходи к следующей фазе без подтверждения пользователя.

Для обнаружения кода предпочитай codebase-memory-mcp: search_graph → trace_path → get_code_snippet → query_graph → get_architecture. Если граф недоступен или недостаточен, используй доступный поиск и отметь ограничение. Для конфигураций и строк допустим rg.
